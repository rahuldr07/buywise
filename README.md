# BuyWise AI — Phase 1 Web App

Phase 1 web-only frontend for Project Happy / BuyWise AI.

## Stack

- Node 24 LTS
- npm 11
- Next.js latest App Router
- TypeScript
- Tailwind CSS v4
- shadcn/ui
- Lenis smooth scroll
- next-themes
- TanStack Query
- Zustand
- React Hook Form + Zod
- Recharts
- Sonner
- Lucide React

## Run

```bash
npm run dev
```

Open:

```txt
http://localhost:3000
http://localhost:3000/product/sony-wh-1000xm5
```

## Validate

```bash
npm run validate
npm run audit:prod
```

## Phase 1 scope

- Homepage
- Product search / paste-link flow
- Product verdict demo page
- Better alternative section
- Price alert login-gate modal
- Watchlist / alerts / deals placeholder routes

Chrome extension, mobile app, receipts, admin dashboard, and chatbot are intentionally not scaffolded in this Phase 1 web script.
